# Browse amaaov essays

Use when an agent needs the amaaov.github.io article index, Markdown mirrors, demos list, or discovery metadata.

## Steps

1. Read `https://amaaov.github.io/llms.txt` for the page list and related technical essays.
2. Prefer the `.md` sibling URL when one exists beside an HTML essay (replace `.html` with `.md`).
3. Open `https://amaaov.github.io/pages.html` for the full articles index.
4. Open `https://amaaov.github.io/demos.html` for interactive demos.
5. Do not expect OAuth tokens or a live MCP session from this hostname; public GET is enough.
